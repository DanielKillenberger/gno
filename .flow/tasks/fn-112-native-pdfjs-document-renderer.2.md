- `src/serve/public/lib/pdf.ts` is the ONLY module that references `pdfjs-dist` — in runtime AND type positions. It must: set `GlobalWorkerOptions.workerSrc = "/vendor/pdfjs/pdf.worker.min.mjs"`; export a `getDocument` wrapper whose init params include `cMapUrl: "/vendor/pdfjs/cmaps/"`, `cMapPacked: true`, `standardFontDataUrl: "/vendor/pdfjs/standard_fonts/"`; **re-export the full surface downstream code needs**: the `TextLayer` class, error classifiers (`classifyPdfError(err): "corrupt"|"password"|"network"|"bootstrap"` and `isRenderingCancelled(err)` — name-based, resilient to minified classes; `"bootstrap"` covers **document-load rejections from worker startup/bootstrap failure only** — missing auxiliary cMap/standard-font data does not necessarily reject `getDocument` and is out of this classifier's scope), and type-only re-exports (`PDFDocumentProxy`, `PDFPageProxy`, `RenderTask`, `PageViewport`, annotation types); own the module-level `__gnoPdfMetrics` channel **exactly as the spec's "Metrics channel contract" defines it** (attach once to `globalThis`; expose `recordEvent(...)` helpers for the hooks plus `reset({capacity})`, `snapshot()`, and `export()`). Each record carries `{seq, t, docId, pageNumber, taskId, genId, kind, outcome, scale, canvasWidth, canvasHeight}` — structured and content-free, **not** "counters only": `seq` is a never-reused monotonic sequence, `t` is `performance.now()` (with a single channel-level `t0Epoch`), `docId`/`taskId` are opaque in-process counters minted by the facade (`d3`, `r17`) and **never** derived from a URL, path, URI, filename, or title, `genId` is monotonic per `docId` and bumped on every zoom/fit/scale commit. Storage is a **bounded ring buffer** (default ~2 000 events) with a `dropped` counter so truncation is always visible; `reset({capacity})` clears records/`dropped`/sequence and may raise capacity for a QA run; `snapshot()` returns a frozen structural clone plus `{capacity, dropped, seqHigh, t0Epoch}` without mutating or truncating the live buffer; `export()` returns its JSON-serializable form; never set `enableScripting`; NOT reference `isEvalSupported` (removed in v5).
- Pure, unit-testable exports (signatures only, implementer's choice of shape): zoom step/clamp math; fit-width and fit-page scale from viewport dims + container dims (must handle landscape/rotated viewports without overflow); effective render scale = `min(devicePixelRatio, 2) * zoom` plus a max-canvas-area clamp (pdfjs core does NOT cap for you); link sanitizer `sanitizeAnnotationUrl(url: string): string | null` allowlisting `http:`/`https:` only.
- Fixtures in `scripts/generate-test-fixtures.ts` (see existing `generatePdf()` at `:23-40`; pdf-lib is a devDependency, hand-authored fixtures are deterministic byte templates in the script): (a) checked-in ~5-page fixture with real selectable text, an external `https:` link annotation, a `javascript:` link annotation, and an internal GoTo destination; (b) checked-in corrupt fixture (truncated valid PDF); (c) checked-in fixture embedding a JS OpenAction (for the no-execution proof); (d) checked-in `standard-font.pdf` — pdf-lib `StandardFonts` base-14 text with NO embedded font program, so PDF.js must fetch from `standardFontDataUrl` (verify with `rg` that no `FontFile` stream is embedded); (e) checked-in `cjk-cmap.pdf` — minimal hand-authored PDF using a Type0 font with `/Encoding /UniJIS-UCS2-H` and a non-embedded CID font, so PDF.js must fetch the packed cMap from `cMapUrl`; (f) checked-in `zero-page.pdf` — minimal hand-authored PDF with an empty `/Pages` tree (`/Count 0`); (g) an exported `generateLargePdf(pages: number)` used on demand by the e2e script — NOT checked in.
- Keep checked-in fixtures tiny (<100 KB each).

- pdfjs v5 npm tarball ships `build/pdf.worker.min.mjs`, `cmaps/`, `standard_fonts/` — the three `/vendor/pdfjs/` routes from task .1 map 1:1; without local `cMapUrl`/`standardFontDataUrl`, PDFs with non-embedded CJK/symbolic fonts trigger non-self fetches and break the offline guarantee (spec R3).
